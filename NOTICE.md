SUNSET FRONTIERS is an original experimental single-player game with procedural and Blender-authored artwork. It is inspired by the broad open-world action/driving genre and is not affiliated with Rockstar Games or an official Grand Theft Auto product. No GTA models, textures, map data, audio or trademarks are distributed as game assets. All included GLBs are original static meshes generated by the accompanying source. The Harbor Workshop pack was authored with Blender; its mesh labels use Blender's bundled Bfont converted to geometry. System UI fonts are referenced, not redistributed. User-imported models remain the user's responsibility.

The independent `showroom.html` includes Google model-viewer 4.3.1 (Apache-2.0), with bundled Three.js (MIT) and Lit (BSD-3-Clause). See `assets/vendor/model-viewer/` for license texts and the pinned source/hash manifest. Upstream license comments are retained in the vendored bundle. This dependency is not included in the offline game build. Showroom HDR lighting data and AR-7 reference renders are original project outputs, generated by `tools/build_showroom_assets.py`.

The Harbor Radiance AgX tone-mapping matrices and polynomial in `renderer-photographic-shaders.js` are adapted from Three.js `tonemapping_pars_fragment.glsl.js` (MIT; copyright the Three.js authors). The complete MIT notice is retained in `assets/vendor/model-viewer/LICENSE-three.txt`. Upstream identifies Filament (Apache-2.0) as the source of part of the AgX color transform; the Apache-2.0 text is retained in `assets/vendor/model-viewer/LICENSE`. Source references are linked in `GRAPHICS_ZH.md`. The outdoor environment map, filtering baker, remaining rendering integration and comparison screenshots are original project work.
