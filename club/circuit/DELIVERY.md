# 港湾赛道俱乐部交付

目标：电脑优先、偏真实驾驶。独立赛事入口与原俱乐部共存，使用同一港湾 Site。原始模型与旧存档不改动。

实施顺序：
1. 四轮接地、悬挂、轮胎抓地与动力总成；M4 试驾、三视角、仪表和输入。
2. 两条手工设计赛道、有效圈与分段计时、幽灵、针对实际圈速记录的反馈与分段重试。
3. M4 / 458 / 2026 SU7 Max、同车 AI 短赛、三站锦标赛、保存与进阶。
4. 物理及规则断言、实际浏览器操作与性能采样、站点构建与原址发布。

物理边界：Rapier 负责唯一刚体世界与碰撞，四轮射线悬挂和合并抓地预算由游戏模块施加力。动力曲线、滑移、ABS/TC、自动换挡与能量消耗是可检验的游戏近似，不宣称工程级轮胎／实车复现。渲染只插值物理结果，120 Hz 固定模拟。

实现：三车、两赛道、试车场、三视角与仪表、练圈／幽灵／分段反馈、同车短赛、三站锦标赛、独立存档和旧俱乐部入口均已接入。原始模型没有改写，运行 GLB 由派生脚本生成。

本地验收完成（2026-09-18）：
- 原俱乐部 107 项回归通过；新物理完整套件 21 项通过，随后增加的真实离开赛道再返回检查单独通过。覆盖三车加速制动、路肩、碰撞、30/60/120 Hz 渲染一致性、十个有效圈、六组完整比赛、分段反馈、存档与再生制动能量。
- 浏览器 23 项检查通过，包括实际键盘加速／三视角／暂停、完整键盘输入比赛、六次换车与 GPU 资源计数、实时仪表和旧存档隔离。空闲手柄连接时的键盘回退、模拟量优先与按钮边沿另行通过。
- 三站锦标赛完整跑通，首站后退出并重新加载可继续第二站，最终积分和历史结果保存。试车场实测加速与制动记录通过。
- 最终公开目录 14 项冒烟检查全部通过，覆盖主线、新旧俱乐部、赛道驾驶、展厅、光影展示和全部页面请求；修复离开赛道页面后音频对象释放与暂停事件的顺序问题。
- 本机 Chromium 1440×900 正常 RAF 整场比赛运行 410.55 秒，约 59.60–60.00 FPS，四车完成、无浏览器异常。最终道路材质改动后，三车 × 两赛道各 12 秒采样约 60 FPS，P95 帧间隔 16.7–16.8 ms。性能结论仅限本机；手柄采用标准 Gamepad API 仿真，未验证实体手柄。
